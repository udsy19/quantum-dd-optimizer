01. The optimizer found nothing the canonical sequences had left

Five results carry the paper. Each number links to the recorded run, the command that produced it and the code commit. Hover, focus or tap a number to see its source.

Pre-registered benchmark (Scenario A)
No CMA-ES mode improves on the training-selected XY4/XY8 baseline in a way that matters. XY8 already sits on the floor set by T1 and white noise, which no pulse sequence can remove.
