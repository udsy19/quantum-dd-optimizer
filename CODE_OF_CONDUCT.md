# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, critique ideas and evidence rather than people, and
assume good faith. Scientific disagreement is welcome and expected; harassment, personal attacks
and discriminatory language are not.

Report unacceptable behaviour privately to the maintainer via
[GitHub private vulnerability reporting](https://github.com/udsy19/quantum-dd-optimizer/security/advisories/new)
(choose a descriptive title) or by contacting the repository owner. Reports are handled
confidentially, and maintainers may remove contributions or block participants who violate this code.
