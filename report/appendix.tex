\section*{Scope}
This supplementary document contains the detailed derivations, numerical methods,
extended result tables, ablations, and run identifiers of the synthetic computational study. It is not evidence of
experimental measurements on IQCC hardware. All numbers are generated from
versioned computation artifacts; see the repository evidence ledger.
Figures, tables, equations and references in this supplement carry an ``S'' prefix
(Fig.~S1, Table~S1, eq.~(S1), [S1]); it has its own reference list, and unprefixed
numbers refer to the main paper.
